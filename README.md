# TARS — Smart Transport And Retrieval System (project demo site)

Static, frontend-only demo website (plain HTML/CSS/JS, no build step).

## Host on GitHub Pages
1. Push these files to a repo (or a `docs/` folder).
2. Settings → Pages → deploy from branch (`main`, `/root` or `/docs`).
3. Open the published URL.

Preview locally: `python3 -m http.server` then visit http://localhost:8000
